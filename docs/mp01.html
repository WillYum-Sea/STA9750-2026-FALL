What We Watched: Exploring Netflix Viewing Data

This project demonstrates the following:

  1. proficiency using the dplyr and gt packages to manipulate data

  2. an understanding of data cleaning and combination

  3. the ability to perform descriptive and inferential statistical analysis

  4. a grasp of data visualizations in R

The goal of this project is to utilize Neflix’s publicly available ‘What We Watched’ report to advise leadership how best to invest their time and money. Using R, we will wrangle the report’s data, perform statistical analysis, and summarize our findings in the form of a formal memo.

We’ll start with getting the data from that report!

Step 1. Acquiring the Netflix What We Watched Reports

This function will acquire and standardize all data for MP#01 from Netflix. Because Netflix hosts the data files behind a CDN, we are accessing the release pages and automatically extracting links to the relevant files (with CDN hash). This chunk also loads the packages we will be using in later sections of the project, so be sure to have those installed if you want to run the code!

Code 
load_netflix_data <- function(){

library(tidyverse)
library(rvest)
library(readxl)
library(fs)
library(dplyr)
library(skimr)

data_dir <- path("data", "mp01")
    
  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings=FALSE, recurse=TRUE)
  }
  
  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )
  
  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
    
    return(local)
  }
    
  NETFLIX_URLS |> 
    map(read_html) |> 
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |> 
    map_chr(html_attr, "href") |> 
    enframe("period", "url") |> 
   mutate(path = path(data_dir, paste0(period, ".xlsx")), 
          path = map2(url, path, download_if_needed), 
          data = map(path, read_excel, skip=3, na="*"), 
          data = map(data, \(x) x |> mutate(`Release Date` = as.Date(`Release Date`)))) |>
    unnest(data) |> 
    select(-url, -path) |> 
    mutate(year=str_sub(period, 1, 4), 
           half=str_sub(period, start=6), 
           period_start = make_date(year, if_else(half==1, 1, 7), 1), 
           period_end = make_date(year, if_else(half==1, 7, 12), if_else(half==1, 30, 31))) |> 
    filter(!is.na(`Hours Viewed`)) |> 
    mutate(live_event = !is.na(Runtime) & str_detect(Runtime, "\\d+:\\d+\\*"), 
           clean_time = str_remove(Runtime, fixed("*")),
           Runtime = 60 * hour(hm(clean_time)) + minute(hm(clean_time))) |>
    select(-clean_time) |>
    mutate(Runtime = coalesce(Runtime, mean(Runtime, na.rm=TRUE)), 
           .by=Title, 
           Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
           Title = str_remove(Title, " // .*"), 
           Title = str_remove(Title, "[^[:ascii:]].*"), 
           Title = str_trim(Title)) |>
    filter_out(Title == "") |>
    select(year, 
           period, 
           period_start, 
           period_end, 
           Title, 
           -half, 
           Runtime, 
           Views, 
           `Hours Viewed`, 
           `Release Date`,
           `Available Globally?`, 
           live_event)
}

Which titles have had the most consistently high viewership across all periods?

#Calculating the mean viewership of all Netflix programming to determine what shows are valid for this prompt (i.e., shows in the 90th percentile or higher of total viewership)
quantile_viewership <- quantile(NETFLIX_DATA$views, 0.90, na.rm = TRUE)

title_stats <- NETFLIX_DATA |>
  arrange(title, period) |>
  group_by(title) |>
  mutate(change = abs(hours_viewed - lag(hours_viewed)),
         total_hours = sum(hours_viewed, na.rm = TRUE)) |>
  summarise(
    avg_change = mean(change, na.rm = TRUE),
    n_periods = n_distinct(period),
    sd_hours = sd(hours_viewed),

    min_views = min(hours_viewed),

To answer this question, we are comparing ‘Coefficient of Variation,’ which is defined as sd(x)/mean(x). We are using this measure because it accounts for both the variation of viewership throughout the periods as compared to its total viewership; this gives a more fair assessment of ‘consistency’ because it accounts for the fact that shows with larger viewership will tend to have larger standard deviations. We will be assuming that ‘consistent’ also means the title is sufficiently large. To account for this, we use a set of titles that have been present for more than 4 periods and that are in at least the 90th percentile of total views.

With that in mind, this graph displays stats of titles with sufficiently high views and a low CV. We can see that are several seasons of Longmire, the second season of Velvet Coleccion, and the ninth season of Hubert und Staller; dramas in 3 different language make up half the list. ‘Neon Genesis Evangelion’ is a popular anime, ‘Superstore’ is a sitcom, and ‘Upin and Ipin’ is a children’s show. All of these shows are something we could reasonably sit down, turn on the television, and watch leisurely. It is also worth noting that these IPs have all been on the platform longer than the parameter set in the analysis, suggesting that longer-running shows are worth investing in.

Reflecting on the previously performed analysis, I recommend:

Catalog Makeup

Netflix’s viewing hours are highly skewed towards show since 2023. In the first half of 2023, watchers spent 66.96% of their time on shows rather than movies. As of the release of the 2026H1 data, that number stands at 89.38%. If we observe our most popular and consistently followed titles, we will see that people tend to rewatch shows, not movies.

Title Consistency

Studying viewership in variance of sufficiently popular shows on Netflix reveals that the most consistent viewership comes from dramas, sitcoms, and children’s shows that have, or could reasonably, appear on cable television. Of the top 10 most consistent shows (view analysis for details on that definition), all 10 are shows that have been available on Netflix for at least 2 years, often with several seasons. They only vary from a CV of 0.03 to 0.05, meaning that there are no special cases here. A large factor in rewatches is palatability, not necessarily a flashy title.

Viewership Concentration

After analyzing viewership concentration across several reporting periods, it is clear that extremely popular titles only make up a small portion of our total viewership. The greatest viewership share we’ve had by hour is 0.01% with ‘Wednesday: Season 2.’ If a highly anticipated title such as that cannot break into 2%, it would be my recommendation to invest in smaller titles.
